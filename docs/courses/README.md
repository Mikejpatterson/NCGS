# Ready-made course cards: where the numbers come from (checked 27 and 29 October 2026)

The owner asked for every society venue's card to be found and checked online, not typed in by him. The cards live in `src/app/16-courses.js`. A printed club card always wins, and the organiser can edit any number afterwards. The direct sites couldn't be opened from the build session, so every figure below was cross-checked through web search, source by source.

The confidence levels say how many independent sources agree, and whether the club's own words back them. They aren't a guarantee: stroke indexes decide where every player gets shots, so the "still to confirm" column matters. Each card shows its note in the app (Organiser → Courses) until it's added or filled in.
